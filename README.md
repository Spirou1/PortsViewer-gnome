# Ports Monitor

A simple GNOME Shell extension to monitor active development and system ports at a glance.

![Ports Monitor Screenshot](https://i.imgur.com/WGdfFAl.png)

## Installation

1. Copy the extension folder to your local extensions directory:
   ```bash
   cp -r . ~/.local/share/gnome-shell/extensions/portsviewer@enzospironelli.com.br
   ```
2. Restart GNOME Shell (Alt+F2, type `r` and Enter on X11, or log out and in on Wayland).
3. Enable the extension using **GNOME Extensions** or **Extension Manager**.
